# 2026-08-03 工作记录

## 为前端博客新增中英文国际化（i18n）

**目标**：给 React 前端加中/英语言切换功能。

**技术方案**：react-i18next + i18next-browser-languagedetector（localStorage 持久化，key=`blog_lang`），默认语言 `zh`。

**新增文件**：
- `client/src/i18n/index.ts` — i18next 初始化（resources/zh、en；fallbackLng=zh；并同步 `<html lang>`）
- `client/src/i18n/locales/zh.ts`、`en.ts` — 全部 UI 文案（嵌套 key，如 nav/home、admin/posts、post/minutesRead 等）
- `client/src/components/LanguageSwitcher.tsx` — 中文/EN 分段切换器

**改动的 UI 文案**：Navbar、Footer、AdminLayout、Spinner、TagCloud、PostCard、Pagination、MarkdownEditor、Home/PostDetail/Tags/TagDetail/About/NotFound 页面、所有 admin 页面；hooks 错误兜底用 i18n 单例 `i18n.t(...)`；`utils/formatDate.ts` 的 `timeAgo` 相对时间也走 i18n（"3 天前" → "3 days ago"）。

**未翻译**：数据库内容（文章/关于页 Markdown）、服务端返回的错误消息（需后端 i18n，本次未做）。

**接入点**：`main.tsx` 顶部 `import './i18n'`；切换器放在 Navbar 与 AdminLayout 的移动端/桌面端。

**验证**：`npm run build`（tsc -b + vite build）通过，EXIT=0。

## 环境注意（重要）
本机 `vite build` 在清空旧 `dist/` 时会调用 WorkBuddy 的 safe-delete / genie-trash 回收站逻辑并失败（`Some operations were aborted`）。
- 临时绕过：在 `vite.config.ts` 加 `build: { emptyOutDir: false }` 后构建，构建完务必改回原样。
- 正常 `dev`（`npm run dev:client`）不受影响，仅 `build` 的清空目录步骤报错。
